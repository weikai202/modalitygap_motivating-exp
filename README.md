# Modality Gap: Motivating Experiments

Screening for early-to-late configuration ranking reversals and changes in modality dependence during adaptation of **Qwen2.5-VL-3B-Instruct** on **MMSD2.0** and **MM-IMDb**, using a single RTX 3090.

See the [experiment plan](docs/experiment-plan.md) for the training matrix, three validation conditions per checkpoint, masking protocol, reversal criteria, and plotting requirements.

**Status:** protocol only. Training, dataset preparation, and implementation have not started. No experimental results are claimed.
